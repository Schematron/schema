# schema
Unofficial copy of schema(s) for Schematron:

- [`schematron.rnc`](schematron.rnc) - RELAX NG schema for Schematron
- [`schematron.sch`](schematron.sch) - Schematron schema for Schematron
- [`svrl.rnc`](svrl.rnc) - RELAX NG schema for Schematron Validation Report Language (SVRL)
- [`svrl.sch`](svrl.sch) - Schematron schema for Schematron Validation Report Language (SVRL)

The RELAX NG and Schematron schemas for Schematron are normative parts of the Schematron standard, and the RELAX NG and Schematron schemas for SVRL are informative.
